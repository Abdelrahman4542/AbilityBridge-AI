# AbilityBridge-AI

**AbilityBridge AI** is an AI-powered accessibility platform designed to help people with hearing, speech, and visual difficulties communicate and interact with their surroundings more independently. The platform is primarily developed in **Arabic**, with English support planned as an optional extension if development time allows. It starts with an accessible interface and an intelligent Voice Gateway that understands the user's intent and automatically routes them to the appropriate assistant. **SignBridge** enables bidirectional communication between deaf users and hearing people by translating sign language into text and speech, and spoken language into sign representation. **AAC-AI** helps people with speech difficulties express themselves by predicting personalized phrases from text, icons, gestures, and conversational context, then converting them into natural speech. **VisionAssist** supports blind and visually impaired users through computer vision, object detection, OCR, and scene understanding to describe their surroundings through speech. The platform integrates **Computer Vision, Natural Language Processing, Speech Processing, Deep Learning, and Personalization** into one adaptive AI-powered communication system.
